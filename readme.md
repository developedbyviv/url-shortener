# URL Shortener

Simple, realistic, used by real companies (bit.ly, tinyurl). Perfect for DevOps practice.

```
User submits long URL → gets short code → visits short URL → redirected
```

## Stack

```
Backend   → Node.js + Express
Database  → PostgreSQL
Frontend  → Simple HTML (keep it simple, we're DevOps engineers)
```

## DevOps Phases

```
Phase 1 → Git setup & project structure
Phase 2 → Docker + Docker Compose
Phase 3 → GitHub Actions CI/CD
Phase 4 → Kubernetes
Phase 5 → Monitoring
```
